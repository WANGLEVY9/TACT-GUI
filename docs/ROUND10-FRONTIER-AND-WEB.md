# 第十轮：预算边界与原生 Web 判定

2026-11-27。算法设计、可检验假设和在线对照见 [异构模型协作与预算调度设计](../research/异构模型协作与预算调度设计-2026-11-27.md)。

## Android 开发轨迹回放

读取上一轮一小时采集的 24 个原始批次。按冻结协议校验角色、初态、终态核验、预算上界和 token 用量。到点中断的文件菜单批次没有可用于配对的最终报告。余下 23 批来自 4 个应用家族、8 个用例。训练每次留出完整应用家族。每个家族每个重复内，把两条用例作为一个预算池。含中断用例的文件应用第三个预算池未进入完整池对照，最终 11 池、22 条候选任务。

拟合直接执行和三个相对于对应控制组的配对收益头，同时拟合各配置的 log-token 头。精确分配与成本感知贪心共享这些预测。每次只执行一个选择，扣该已观测分支的实际开销后重算。所有策略使用相同池、硬预算和可行配置。紧、中、全预算在每个池内以注册上界逐资源取最小、最大、总和。token 的软价格固定为每记录 token 0.00001 个预期完成单位。取值用于机制检查，未经单独验证集选择。

| 策略 | 紧预算确认数 / 记录 token | 全预算确认数 / 记录 token |
| --- | ---: | ---: |
| 固定直接执行 | 8 / 65,471 | 16 / 148,926 |
| 固定带停止提示的直接执行 | 9 / 66,103 | 17 / 151,149 |
| 固定自我复核 | 11 / 62,992 | 17 / 159,119 |
| 固定独立诊断 | 10 / 63,127 | 18 / 160,027 |
| 执行槽规则 | 9 / 66,103 | 15 / 164,113 |
| 相同预测器的贪心 | 7 / 65,414 | 15 / 149,115 |
| 精确分配 | 7 / 65,414 | 15 / 149,115 |
| 精确分配，零 token 价格 | 7 / 65,414 | 15 / 154,301 |

中预算结果与紧预算相同。有限池中精确分配与贪心没有差异。全预算的软价格减少 5,186 个已记录 token，确认数同为 15，仍低于最强固定策略。这里只能判断这些特征、预测器与覆盖的配置不足以胜过固定策略。所有分支是同一个 GUI-Plus 快照。历史设备账本使用采集时的实际记录，跨平台重构当时漏记部分初态读取，表中不解读设备操作节省。重复运行不能增加独立的应用数，新应用在线效应仍待测。

精确求解器通过 40 个随机小问题与独立穷举作对照。一次合成压力测试包含 80 个任务及 320 个备选配置，在模型调用 90、环境操作 700 的上限内生成 30,244 个非支配点，用时约 5.5 秒。合成数据只用于工程性能检查。

## Web 原生 benchmark 适配

使用未修改的 [MiniWoB++ v1.1](https://github.com/Farama-Foundation/MiniWoB-plusplus/tree/a7658beb68e1d3572329e06734c5822bd284ddc8)。通过本地 HTTP 站点启动 Playwright 1.49.1 和 Chromium 131.0.6778.33。应用资源限制在本地来源。三个原生任务 `click-button`、`click-dialog`、`click-button-sequence` 各跑 8 个固定种子。模板控制器只用可见指令、按钮标签和位置。每次用新浏览器上下文重新初始化，核对可见初态散列，将点击坐标重放，并读取原生 raw reward。

- 24 个正向测试中 23 个通过。余下 1 个因两个 `okay` 候选触发模板弃权，记录保留。
- 8 个反序点击对照均在原始轨迹和重放中得到原生负奖励。32 个实例的初态散列全部一致。
- 对弃权实例单独恢复同一初态，分别点击两个候选。两条轨迹均得到正奖励，独立重放也都成功。因此，候选数量和有后果的歧义需要分开。候选等价性由此次离线审计发现，实时选择器没有读取该信息。
- 主探针结算 410/416 个逻辑操作，歧义审计单独结算 20/20，均无未决条目和外部模型请求。

同时修复共享机制入口。初态断言、散列和特征共用一次受账本计量的观察。Web 重置创建新上下文，工作线程在切换站点时先关闭原浏览器会话。另用三份本地测试页面与两个 Chromium 工作线程验证多站点运行，9 条分支全部通过初态与重放核验，结算 96 个逻辑操作。MiniWoB++ 探针的模板仅覆盖指定动作样式，未测 Web 多模型收益。

  results/benchmark-assets/miniwob-v1-1

  results/benchmark-assets/miniwob-v1-1 results/round10-frontier/miniwob-audited

运行入口会拒绝覆盖已有输出。Android 回放需要本机上一轮采集保存的协议、分支报告、批次索引和归档数据。Web 输出包括浏览器版本、种子、每个实例的原始截图、重放截图、初态散列和原生判定。
