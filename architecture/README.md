# 固定预算下的自适应多智能体测试架构

[查看架构图（SVG）](architecture.svg)

本图是研究候选设计，不表示模型、预算保障或实验已实现。SVG 可用矢量编辑器或文本编辑器修改。

运行时闭环：状态与任务管理 → 收益及成本估计 → 联合调度 → 预算准入与账本 → 多智能体执行 → 验证与状态更新。账本通过执行前预留和实际结算控制支出；严格保证依赖费用上界可执行且所有成本均被计入。验证需求预测不等于已预留预算。

训练和评估：在可恢复的相同状态下受控比较配置并记录完整轨迹；根据数据规模选择训练技术；用同预算和同权限的基线及消融评估。针对反事实估计，应明确干预、后续策略、预算口径并控制状态干扰。

实施时先选定具体测试场景、确认缺陷验证标准和执行环境，再实现统一账本与基础配置。ScenGen 仅为候选，需先检查模块接口、恢复能力和成本日志。
